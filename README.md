## 📌 О проекте
**AlmatyAir-Graph** — система прогноза концентрации **PM2.5 на 1–48 часов** для Алматы с интервалом неопределённости. Учитывает зимнюю температурную инверсию, горно-долинную циркуляцию и основные источники выбросов. Использует пространственно-временную графовую нейросеть (ST-GNN): узлы — станции мониторинга, связи учитывают расстояние, **перепад высот** и ветер.

> **Статус: рабочий прототип.** Код, модели, API и веб-карта работают «из коробки». Модели в `models/` обучены на **синтетических** данных (`data/sample/`), которые воспроизводят физику смога в котловине. Это сделано, чтобы проект запускался без ключей и интернета. Для реального прогноза модели переобучаются на измерениях станций одной командой (см. «Реальные данные»).

## 🎯 Решаемая проблема
Зимой Алматы регулярно оказывается среди городов с самым загрязнённым воздухом. Котловина у подножия гор, слабый ветер и инверсия запирают выбросы над городом на несколько дней. Жителям и городским службам нужен не только факт «сейчас грязно», но и **прогноз**: когда начнётся эпизод смога и когда он закончится.

## ✅ Что реализовано
| Компонент | Файл | Описание |
|---|---|---|
| Калибровка недорогих датчиков | `almatyair/calibration.py` | Модель гигроскопического роста `raw = a + b·pm·(1 + κ·RH²/(1−RH))` по совместным измерениям со станцией Казгидромета |
| Граф станций | `almatyair/graph.py` | Вес ребра: расстояние × перепад высот; ветровая (направленная) матрица |
| Признаки | `almatyair/features.py` | История PM2.5, соседи, **метеопрогноз на горизонт** (ветер, высота слоя перемешивания, температура), агрегаты прогноза по окну |
| Базовые модели | `almatyair/models/baselines.py` | «Завтра как сегодня», LightGBM (квантили 10/50/90 % + конформная калибровка интервала) |
| ST-GNN | `almatyair/models/stgnn.py` | GRU-энкодер → графовая свёртка (физическая + адаптивная матрица, как в Graph WaveNet) → GRU-декодер по метеопрогнозу → 3 квантиля на каждый час 1–48; экспорт в ONNX |
| Метрики | `almatyair/metrics.py` | RMSE/MAE, точность категорий AQI, POD/FAR, покрытие интервала, **ошибка начала и окончания эпизода** |
| Карта | `almatyair/interp.py` | Интерполяция между станциями с учётом высоты (IDW × рельеф) |
| API | `almatyair/api.py` | FastAPI: `/api/forecast`, `/api/forecast/live`, `/api/map`, `/api/stations` + веб-карта |
| Реальные данные | `almatyair/data/` | Open-Meteo (ERA5, архив прогнозов, оперативный прогноз, **CAMS**), OpenAQ v3 |
| Синтетика | `almatyair/synthetic.py` | Ящичная модель котловины: инверсия, фронты, сток с гор, частный сектор, ТЭЦ-2, транспорт, высота станций, влажностное завышение датчиков |

## 📊 Результаты (синтетические данные, тест — июль 2024 – июнь 2025)
Синтетический архив — 4 года: обучение 2021-07…2023-06, калибровка интервалов и выбор эпохи — полный следующий год (2023-07…2024-06), тест — ещё один год без подглядывания. Прогноз выпускается в любой час суток.

| Модель | Горизонт | RMSE | MAE | Точность AQI | POD | FAR | Покрытие 80 % |
|---|---|---|---|---|---|---|---|
| «Как сегодня» | 24 ч | 11.7 | 5.3 | 0.82 | 0.79 | 0.21 | — |
| LightGBM | 24 ч | 5.3 | 2.8 | 0.89 | 0.88 | 0.10 | 0.80 |
| **ST-GNN** | 24 ч | **4.5** | **2.5** | **0.90** | **0.90** | **0.07** | 0.80 |
| «Как сегодня» | 48 ч | 13.8 | 6.2 | 0.79 | 0.76 | 0.24 | — |
| LightGBM | 48 ч | 6.8 | 3.4 | 0.88 | 0.86 | 0.12 | 0.80 |
| **ST-GNN** | 48 ч | **5.2** | **2.8** | **0.88** | **0.88** | **0.08** | 0.78 |

Эпизоды смога (> 55.5 мкг/м³, среднее по городу, прогноз на 24 ч): из 48 эпизодов ST-GNN поймала 46, «как сегодня» — 35. Ошибка **окончания** эпизода: 4.4 ч у «как сегодня», 0.9 ч у LightGBM, **0.6 ч у ST-GNN**. Полная таблица по всем горизонтам — в [`results/benchmark.md`](results/benchmark.md).

> ⚠️ Это проверка конвейера на синтетике, где «правильная» физика известна. Преимущество ST-GNN на реальных станциях нужно доказать заново: станций мало, а качество ограничено метеопрогнозом. Результат сравнения публикуется в любом случае.

## 🌡 Что определяет смог в Алматы
| Фактор | Влияние | Источник данных |
|---|---|---|
| **Температурная инверсия, высота слоя перемешивания** | Главный фактор: «крышка» над городом | ERA5 (история), GFS / ICON (прогноз) — через Open-Meteo |
| Скорость и направление ветра | Проветривание котловины | Метеостанции, ERA5, прогнозы |
| Горно-долинная циркуляция | Ночной сток холодного воздуха с гор, дневной подъём | Время суток + направление ветра |
| Температура воздуха | Чем холоднее, тем больше сжигается топлива | Метеостанции |
| **Угольная ТЭЦ-2** | Крупный точечный источник | Расстояние и направление ветра от ТЭЦ |
| **Частный сектор с угольным отоплением** | Низкие выбросы, сильнее всего на окраинах | Доля частного сектора у станции |
| Транспорт | Утренний и вечерний пик | Время суток, день недели |

## 🛰 Реальные данные
```bash
export OPENAQ_API_KEY=...                                     # бесплатно: explore.openaq.org
python scripts/fetch_openaq.py --list                         # станции и датчики PM2.5 в радиусе 25 км
cp data/stations_template.csv data/stations.csv               # впишите sensor_id, уточните координаты и высоты
python scripts/fetch_openaq.py --start 2022-10-01 --end 2025-04-30
python scripts/fetch_openmeteo.py --stations data/stations.csv --start 2022-10-01 --end 2025-04-30 --out data/raw/met_era5.csv
python scripts/fetch_openmeteo.py --stations data/stations.csv --start 2024-07-01 --end 2025-04-30 --cams --out data/raw/cams.csv
python scripts/build_dataset.py --stations data/stations.csv --openaq data/raw/openaq.csv --met data/raw/met_era5.csv --out data/almaty_real.csv.gz
python scripts/train.py --data data/almaty_real.csv.gz --stations data/stations.csv --cams data/raw/cams.csv --colocation ''
```
* **Калибровка.** Лучший вариант — совместное размещение датчика рядом со станцией Казгидромета на 2–4 недели (`--colocation file.csv` с колонками `pm25_raw, rh, pm25_ref`). Без него датчик калибруется только по станции ближе 5 км и на той же высоте: иначе в коэффициенты попадёт реальная разница загрязнения между районами.
* **Метеопрогноз при обучении.** По умолчанию — «perfect prognosis + шум»: метео на t+h берётся из ERA5 и зашумляется пропорционально заблаговременности. Для честной оценки используйте архив реальных прогнозов: `fetch_openmeteo.py --source forecast`.
* **CAMS** — обязательная базовая модель; передаётся в `train.py --cams` и попадает в таблицу сравнения.

## 🛰 О спутниковых данных
Sentinel-5P **не измеряет PM2.5**: один пролёт в сутки, разрешение несколько километров, зимой мешают облачность и снег — как раз в периоды сильнейшего смога. В проекте он не используется для прогноза.

## 🚧 Ограничения
* Станций в городе десятки, граф небольшой; преимущество ST-GNN на реальных данных нужно доказать.
* Качество прогноза ограничено качеством метеопрогноза.
* Разовые события (пожары, аварийные выбросы) не учитываются.
* Недорогие датчики даже после калибровки менее точны, чем официальные станции.
* Координаты станций в `almatyair/stations.py` — ориентировочные (центры районов).
