# Участие в проекте

Спасибо за интерес! Особенно нужны метеорологи, специалисты по качеству воздуха и владельцы сетей датчиков.

## Как помочь
* **Данные.** Координаты и высоты реальных станций (`data/stations_template.csv`), результаты совместного
  размещения недорогих датчиков со станциями Казгидромета (`pm25_raw, rh, pm25_ref`) — это самое ценное.
* **Код.** Откройте issue с описанием задачи, затем pull request. Перед PR: `pytest -q`.
* **Проверка.** Если вы запустили модель на реальных данных — опубликуйте `results/benchmark.md`
  в issue, даже если ST-GNN проиграла базовым моделям.

## Правила
* Стиль — PEP 8, строка до 120 символов.
* Новые признаки и модели сопровождаются тестом и сравнением с базовыми моделями.
* Не коммитьте ключи API и сырые выгрузки (`data/raw/` в `.gitignore`).
